Poisoning means retraining the models on tampered training data. The training data is not part of the demo bundle and each retrain is slow, so these are the results of the pre-registered run, shown exactly as logged.

Before any model loads, the app checks, in order: the signature (against a key built into the app), the version (must be version 4), the file list, and every file's SHA-256. Models are plain arrays (no pickle), so a bad file cannot run code. Every test runs on a copy of the bundle.
